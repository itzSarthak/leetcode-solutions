# 198. House Robber

**Difficulty:** Medium  
**Language:** C++  
**Solved:** 2026-08-15 23:14  
**LeetCode:** https://leetcode.com/problems/house-robber/

## Problem

You are a professional robber planning to rob houses along a street. Adjacent houses cannot both be robbed. Return the maximum amount of money you can rob.

## Complexity

Time: O(n), Space: O(1)
